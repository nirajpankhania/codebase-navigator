What does this repository do?
This is a Codebase Navigator — an AI-powered tool for chatting with any GitHub repository.

The main flow: (1) you paste a GitHub URL, (2) the backend fetches all source files and chunks them, (3) embeds each chunk with text-embedding-3-small, stores vectors in Supabase pgvector, then (4) answers questions by retrieving relevant context and passing it to gpt-4o-mini.
